# Flyer B — Eschooly Parent App

**Use only the “Confirmed for promotion” block on the A4 flyer.**  
Do not advertise fees, payments, chat, or diary as live services.

**Accuracy note for the designer (not for print):** Parent features below are wired to child APIs in the app. Live school servers were not independently tested here. Prefer “in the Parent app” / “for each linked child”. Do not say “live GPS” or “pay school fees in the app”.

---

## Headline

**Know how your child is doing at school.**

Alternatives:

- **One parent login. Every linked child.**
- **Attendance, results, and the school day — on your phone.**

## Introductory description

Eschooly Parent is for families. Sign in with a family ID, choose a child, and follow that child’s attendance, timetable, syllabus, results, library, announcements, and exam dates. Switch child when more than one student is linked to the account.

## Key features (confirmed for promotion)

| Feature | Flyer explanation | Suggested visual / icon |
| --- | --- | --- |
| Parent home | See a snapshot for the selected child: attendance, library, exams, and notices. | Parent holding a phone; family dashboard |
| Linked children | Switch between children linked to your family account. | Two student avatars / switch control |
| Attendance | Follow this month’s presence, absences, and daily history. | Attendance calendar |
| Timetable | Open the full week’s periods and teachers. | Class schedule |
| Syllabus | See how far the class has moved through each subject. | Textbook with progress |
| Results | View grades and open the result card. | Report card |
| Exam dates | Check upcoming papers, times, venue, and outline. | Exam calendar |
| Digital library | Browse resources issued for that child’s class. | Books / PDF |
| Announcements | Read school notices for the selected child. | Megaphone |
| Child journey | See whether transport is assigned and the day’s pickup and drop steps. | School bus (not a live city map) |
| Parent profile | View your account, change your password, and sign out. | Adult profile / shield |

**Child journey / transport:** The app shows allocation and trip **steps** from school records. The map on screen is a static illustration. Print “pickup and drop status”, never “live GPS tracking”.

## Main parent benefits

- One family login for every linked child  
- Attendance and results without waiting for a paper notice  
- Timetable, syllabus, and exam dates in the same place  
- School announcements for the child you are viewing  
- Transport assignment and trip steps when the school provides them  

## Optional combined line

“Built for parents who want a clear view of each child’s school day.”

## Do not print (excluded)

- Paying fees, viewing live balances, downloading challans, or payment history as a working service  
- In-app chat with teachers  
- Parent diary as a live school diary  
- Teacher directory as a live data service  
- Assignment submission by the parent  
- Online classes for parents  
- Notification inbox as a full live feed (a count may appear on home; the list is not parent-API backed)  
- “Track the bus on a live map”  
- Testimonials, ratings, or “used by X schools”  

## Tone

Reassuring and factual. Address the parent (“your child”, “your family account”). Avoid surveillance language (“monitor 24/7”, “never miss a moment”).
