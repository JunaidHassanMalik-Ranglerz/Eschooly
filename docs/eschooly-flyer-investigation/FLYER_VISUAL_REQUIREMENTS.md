# Flyer visual requirements

The flyer designer will use the **separately approved** Eschooly branding. Do not copy the current in-app colour system or layout. This file only recommends **subjects** for illustrations, icons, and screenshots.

Do not generate images in this repository.

---

## 1. Hero illustrations

### Student flyer

- A secondary-school student with a backpack, looking at a phone that shows a class timetable or home shortcuts.  
- Optional background: classroom or campus path, uncluttered.  
- Avoid childish cartoon mascots unless the approved brand already uses them.

### Parent flyer

- An adult (parent/guardian) reviewing a child’s attendance or report on a phone, with a school-age child nearby — not looking over a shoulder in a secretive way.  
- Tone: partnership with the school, not surveillance.

### Combined overview flyer

- Two devices or two people: student on the left (timetable/assignments), parent on the right (child snapshot).  
- A small family-id / student-id motif is enough to show two portals; do not invent extra products.

## 2. Feature icons (3D educational, one concept each)

Use **individual** transparent icons, not a collage cropped from a full UI mock.

| Feature | Icon concept |

## 3. Screenshots worth displaying

Only show screens that match **confirmed** flyer features. Prefer a later approved UI design if that is what the flyer brand uses; do not treat today’s navy gradient UI as mandatory.

### Student flyer (priority)

1. Student Home — greeting and module shortcuts  
2. Timetable — one day’s periods  
3. Assignments — overview or a subject with a submit action  
4. Results — grades or result card  
5. Online class card **or** Digital library list (pick one if space is tight)  

### Parent flyer (priority)

1. Parent Home — child snapshot tiles  
2. Child switch (if the screenshot clearly shows more than one child)  
3. Attendance summary  
4. Results card  
5. Exam schedule **or** Child journey steps (not the static map as if it were live GPS)  

### Avoid on flyers

- Chat thread (demo messages)  
- Online exam question paper (dummy)  
- Fees / Pay Now  
- Dummy diary entries  
- Login screen with visible demo passwords  
- Empty loading spinners  

If a screenshot still shows placeholder names, replace with generic “Student name” / “Class” in design, or wait for a staged capture.

---

## 4. Layout notes for A4

- One hero + 6 to 8 feature pairs (icon + 1–2 lines) fits a single A4 without crowding.  
- Student flyer: 8 features if you drop Holidays and Profile to a footer line.  
- Parent flyer: 8 features if you drop Profile and Library to a footer line.  
- Keep a small legal-style line: two portals (Student / Parent), school-enabled modules may differ.

---

## 5. Combined overview (Flyer C) visual

- Split panel: “For students” vs “For parents”.  
- Shared centre: school building or Eschooly wordmark.  
- Three student bullets + three parent bullets maximum (see approval checklist).
